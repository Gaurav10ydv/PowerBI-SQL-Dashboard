📊 Customer Behavior Dashboard Analysis
🚀 Project Overview

This project focuses on analyzing customer shopping behavior and sales trends using SQL, Python, and Power BI. The main objective is to transform raw customer data into meaningful business insights through data analysis and interactive visualizations.

The dashboard helps businesses understand:

Customer purchasing patterns
Revenue performance
Product category sales
Age-group behavior
Subscription trends

📈 Dashboard Insights
Key Findings:
Clothing category generated the highest revenue and sales
Young adults contributed the highest customer spending
Most customers were non-subscribers
Average customer review ratings remained positive
Accessories and footwear also showed strong performance
